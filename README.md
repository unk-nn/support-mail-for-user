# support-mail-for-user
This repository is not a training repository and is only needed for local use.

You can view the implementation of creating an answering machine to automate the project and rewrite it for yourself. But you won't find any detailed instructions.

To start, make changes to the following lines:
```pythonfile
    email = "your_email@gmail.com" # the email from which the messages will be sent
```
```pythonfile
    auth_code = "aaaa aaaa aaaa aaaa" # your special authorization code
```

After that, call one of the two necessary functions, pass the parameters (the id parameter can be specified by any key in the int type) and run. 
P.S. An example of the launch can be found on the last line of the file. support_mail.py
